## Architecture & System Overview

Knowledge Exploder (Graphiverse v2.6.0) is a recursive knowledge expansion and self-optimizing graph engine designed for dynamic sub-graph synthesis, real-time node topology generation, and automated semantic context navigation.

### Core Modules
- **Graphiverse Core Engine**: Manages high-dimensional graph topology, state tracking, and node propagation algorithms.
- **Gemini Sub-Graph Synthesizer**: Leverages Google GenAI models to perform recursive query expansion, entity extraction, and sub-graph generation.
- **Interactive Visualization Panel**: WebGL/D3/Three.js renderers for rendering node systems and real-time user manipulation.
- **System Services & API Server**: Express-based backend for handling client sessions, websocket events, and model interactions.
